## 阅读与反馈

无需登录。页面地址可直接复制分享；书签只保存在当前浏览器。精读内容标注核验状态并链接到所读版本的原文位置；引用次数是 OpenAlex 的历史快照。

如果发现事实、引用、翻译或页面问题，可以在本仓库 [Issues](https://github.com/zhitwang17/zhitwang17.github.io/issues) 中记录论文名称、页面地址、具体问题和可核对的原文出处。后续内容由维护者审核更新。

## 发布方式

本仓库仅存放公开网站的编译产物。开发仓库通过自动化验证后，将站点同步到 `low-precision-training-kb/`；GitHub Pages 从 `main` 分支根目录发布。网站子目录中的文件由构建生成，手工修改会在下次发布时被覆盖。

论文与引用资料的权利归各原作者所有。本站整理内容用于研究阅读，具体结论以所链接的原文、实验设置和限制为准。
